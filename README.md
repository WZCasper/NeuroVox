# NeuroVox

Озвучивание субтитров в оффлайн играх для ПК.

Офлайн-приложение для Windows, которое **читает русские субтитры игры с экрана и озвучивает их
выразительным голосом** в реальном времени. После первой загрузки моделей интернет не нужен.

## Скачать и установить

1. Откройте страницу **[Releases](https://github.com/WZCasper/NeuroVox/releases/latest)**.
2. В разделе *Assets* скачайте **`NeuroVox-Setup.exe`** и запустите его (права администратора не нужны).
   Не хотите устанавливать — скачайте **`NeuroVox-windows-x64.zip`**, распакуйте и запустите `NeuroVox.exe`.
3. Windows может показать окно «Windows защитила ваш компьютер»: программа пока не имеет платной цифровой
   подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. При **первом** нажатии «Запустить» программа скачает модель голоса Silero и модели распознавания
   EasyOCR (нужен интернет, несколько сотен мегабайт). Дальше всё работает без интернета.

Требования: Windows 10/11 (64-бит), около 3 ГБ свободного места, 8 ГБ ОЗУ и больше (рекомендуется 16 ГБ).
Видеокарта не важна: всё считается на процессоре, поэтому подходят и карты AMD.

Данные программы (модели, настройки, журнал) лежат в `%LOCALAPPDATA%\NeuroVox`.

## Возможности

- Прозрачная рамка, которую перетаскивают на область субтитров и растягивают за правый нижний угол.
- Захват экрана 3–4 раза в секунду (`mss`), бинаризация кадра для точного распознавания.
- Распознавание текста: **EasyOCR** (работает сразу) или **Tesseract** (быстрее, нужна отдельная установка).
- Фильтр повторов: очистка от мусора (`]`, `|`), нечёткое сравнение — фраза с похожестью выше 85 %
  не озвучивается повторно; недопечатанные строки ждут, пока текст «устоится».
- Озвучка **Silero TTS** (голоса: Байя, Ксения, Айдар, Евгений) на процессоре — без CUDA.
- Интерфейс не зависает: захват, распознавание и озвучка работают в отдельных потоках.
- Настройки (голос, скорость, громкость, положение рамки) сохраняются между запусками.

## Как пользоваться

1. Запустите игру в **оконном режиме без рамки** (Borderless) — поверх полноэкранного режима рамка может не отображаться.
2. Запустите NeuroVox, перетащите голубую рамку на область субтитров и растяните её.
   Точная подстройка: стрелки на клавиатуре (`Shift` — крупный шаг, `Ctrl` — менять размер).
3. Нажмите **«Запустить»**. Журнал покажет распознанный текст и состояние.
4. Кнопка **«Проверить голос»** проигрывает тестовую фразу.

### Tesseract (необязательно)

Для более быстрого движка установите [Tesseract-OCR для Windows](https://github.com/UB-Mannheim/tesseract/wiki)
и в списке языков отметьте **Russian**, затем выберите «Tesseract» в настройках программы.
Если Tesseract не найден, программа сама переключится на EasyOCR.

## Если что-то не работает

- **Программа сообщает об ошибке** — нажмите кнопку **«Папка журнала»** и пришлите файл `neurovox.log`.
- **Ошибка про DLL при запуске** — установите
  [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe).
- **Антивирус ругается** — сборки на PyInstaller иногда вызывают ложные срабатывания. Файлы собираются
  автоматически в GitHub Actions из открытого кода этого репозитория; при желании соберите программу сами.
- **Текст не распознаётся** — сделайте рамку плотнее вокруг субтитров; нужен хороший контраст текста с фоном.
- **Рамка «съезжает» относительно текста** — проверьте, что игра и NeuroVox запущены на одном мониторе.
- **Нет звука** — проверьте устройство вывода Windows; кнопка «Проверить голос» покажет причину в журнале.

## Для разработчиков

### Запуск из исходников

Нужен Python **3.10 – 3.12** (64-бит).

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Либо дважды щёлкните `start.bat` — он сделает то же самое.

### Сборка `.exe`

Готовые сборки создаёт GitHub Actions (`.github/workflows/build.yml`): при создании тега вида `v1.0.0` он
собирает программу, проверяет её (тесты + самопроверка со скачиванием реальных моделей) и публикует релиз.
Запустить сборку без релиза можно вручную во вкладке *Actions*.

Локально:

```bat
pip install pyinstaller pyinstaller-hooks-contrib
pyinstaller --noconfirm --clean NeuroVox.spec
```

Результат — папка `dist\NeuroVox` с `NeuroVox.exe`.

### Проверки

```bat
python -m unittest discover -s tests -t . -v
NeuroVox.exe --selftest --strict --models --out otchet.txt
```

Вторая команда проверяет собранную программу изнутри: библиотеки, интерфейс, синтез речи всеми голосами
и распознавание текста; результат пишется в файл отчёта.

### Структура проекта

| Файл | Назначение |
|------|-----------|
| `main.py` | Точка входа, логирование, DPI, перехват ошибок, режим `--selftest` |
| `gui.py` | Главное окно (CustomTkinter) |
| `overlay.py` | Прозрачная рамка выбора области |
| `capture.py` | Захват экрана и бинаризация |
| `ocr_engine.py` | EasyOCR и Tesseract с автопереключением |
| `text_filter.py` | Очистка текста и фильтр повторов |
| `tts_engine.py` | Загрузка модели Silero и синтез речи |
| `workers.py` | Потоки, очереди, воспроизведение звука |
| `selftest.py` | Самопроверка собранной программы |
| `config.py` | Настройки, константы, папки данных |
| `NeuroVox.spec` | Конфигурация сборки PyInstaller |
| `installer/NeuroVox.iss` | Установщик (Inno Setup) |
| `tests/` | Модульные тесты |
